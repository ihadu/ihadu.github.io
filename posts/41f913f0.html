Python Lambda函数

Python Lambda 函数被称为匿名函数，它是在没有名称的情况下定义的。Python 允许我们不以标准方式声明函数，即使用 def 关键字。相反，匿名函数是通过使用λ关键字声明的。但是，Lambda 函数可以接受任意数量的参数，但是它们只能以表达式的形式返回一个值。

匿名函数包含一小段代码。它模拟 C 和 C++的内联函数，但并不完全是内联函数。
